HOW IT HELPS

Specific questions. Clear answers.

01 / UNDERSTAND

Read the full context

It distinguishes a bank warning from a request to share an OTP, PIN, scan a QR code or install an app.

02 / VERIFY

Check the contact route

For a caller, it asks for the bank or app, caller number and contact route. A number is never assumed genuine.

03 / ACT

Choose the safe step

Use the official banking app, website or branch. If money was lost to fraud, call 1930 promptly.
